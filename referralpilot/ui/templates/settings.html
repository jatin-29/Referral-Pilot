How the browser edition works

  • The whole app runs inside this tab (Python compiled to WebAssembly); nothing you enter is uploaded anywhere.
  • Job boards are crawled every few hours by a scheduled GitHub Action, and live from the browser for boards that allow it.
  • Timers (sending, follow-ups, reply checks) only run while the tab is open. Keep it open, pinned, on the days you send.
  • Resumes are built with the pure-Python PDF engine; use Open in Overleaf on a job for the LaTeX version.
